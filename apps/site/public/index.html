copy2llm

A "Copy to LLM" button any website can embed. On click it converts the current page to clean Markdown and lets a reader copy it, view it raw, or open it straight in ChatGPT or Claude.

Free in beta · fully client-side · no accounts, no backend. The button in the corner of this page is the real thing — try it.

Add it to any site with one tag:

<script src="https://copy.computer/copy2llm.js" defer
        data-position="bottom-right" data-theme="auto"></script>

Or, for developers:

npm i copy2llm-react   # <CopyToLLM />
npm i copy2llm-core    # extract(document) -> { markdown, title, url }
